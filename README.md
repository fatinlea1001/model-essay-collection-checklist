# Model Essay Collection — Checklist

Standalone, read-only GitHub Pages site for classes **5C** and **5F**.

## Contents
- **22–28 December 2026:** Balanced Diet, Holiday Destination, Mobile Phone Application
- Each essay links directly to its existing **EASY** and **NORMAL** pages in the separate \`language-games\` repository.
- Two static, class-level checklists, initially not marked. These are **not** individual student records or interactive checkboxes.

## Updating
All public content is in \`index.html\`. Students cannot update checklists from the website. Only people with repository write access can change the content.

Ask ChatGPT to update the next assigned essays or the checklist status. Do not assume an essay is checked unless the teacher confirms it.

## Publishing
GitHub repository **Settings → Pages → Build and deployment → Deploy from a branch**. Choose **main** and **/(root)**, then save.

Public site URL: https://fatinlea1001.github.io/model-essay-collection-checklist/

The \`language-games\` repository is not modified by this website.
